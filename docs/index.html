The problem

The simple case got complicated.

Opening a few RDP sessions to machines you already know — locally, in one window, without signing into anything — quietly got worse. Three ways:

🔒 The vendor gated the basics

Windows is retiring the plain Remote Desktop app for one that wants a work or school account — and, at least for now, won't even do plain RDP to a machine on your own network.

🗂 The built-in client has no tabs

Every session is its own identical window. It's genuinely easy to type into the wrong box — the production one — because they all look the same.

⚖️ Every alternative has a catch

The popular free manager saves passwords in plaintext. The powerful one wants a paid server just to share your list. The old standby was pulled once and feels abandoned.

SimpleRDP is the missing middle — the 95% case, done.

Features

Everything a remote desktop client should have. Nothing it shouldn't.

Multiple sessions, in tabs

Connect to several servers at once and switch between them like browser tabs. Each tab is a real, full RDP session with a live status dot.

Connect by IP — no account

No directory, no discovery, no sign-in, no agent on the far end. Point it at an IP and port, and go.

Passwords done right

Remembered passwords are encrypted with Windows DPAPI — never stored in plaintext. Your connection list is a plain file you own.

Windows & macOS

Native on both. Real embedded RDP on Windows; the macOS client manages the same connections and launches FreeRDP.

Local & private by default

No cloud sync, no telemetry, no relay server. Sessions go straight from your machine to yours — and it still does plain local RDP.

Free & open source

MIT licensed. Read it, build it, change it. No seats, no trial, no upsell, and no server to run.

How it works

From download to connected in under a minute.

Add a server

Enter an IP (or hostname) and port. Add a username if you like. Give it a friendly name.

Save it

It joins your local list. No vault to unlock, no workspace to join — just a file on your disk.

Connect — as many as you need

Click to open a full RDP session in a tab. Open a second, a third. Switch between them freely.
